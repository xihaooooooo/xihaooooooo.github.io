TCP 三次握手与四次挥手
客户端 → 服务端：SYN  
    “我想和你建立连接。”
服务端 → 客户端：SYN + ACK  
    “收到，我也同意建立连接。”
客户端 → 服务端：ACK  
    “收到，那连接建立。”
客户端                服务端
  | ---- SYN --------> |
  | <- SYN + ACK ----- |
  | ---- ACK --------> |
        连接建立
四次挥手：TCP 断开连接的过程。
客户端 → 服务端：FIN  
    “我不再发送数据了。”
服务端 → 客户端：ACK  
    “收到。”
服务端 → 客户端：FIN  
    “我也不再发送数据了。”
客户端 → 服务端：ACK  
    “收到，连接断开。”
客户端                服务端
  | ---- FIN --------> |
  | <---- ACK -------- |
  | <---- FIN -------- |
  | ---- ACK --------> |
        连接关闭

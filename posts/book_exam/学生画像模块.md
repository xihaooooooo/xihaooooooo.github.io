需求：让系统不仅知道哪道题错了，而且知道怎么更好的制定练习计划

1
第一步就是得基于事实来，不能凭借印象来出题。事实就是对于错题会有很详细的记录，比如记录错题的答题时间，答题的自信度，题目的topic，答错题的原因。基于事实的好处就是可以根据事实来进行定量的出题，用一些科学的算法来得出应该出什么，而不是LLM来进行控制。

2
那错因标签是怎么来的呢？很简单就是在判题的时候加的。对于选择题和填空题本身是规则判题，一旦答错了就会调用LLM对错题和错误选项进行分析。简答题就直接进行分析即可。

3
那有了错因标签之后，它是根据不同的章节来进行错因归纳。因为每道题都有章节知识点，所以可以进行归纳。归纳的结果有两个，一个是熟练度，一个是主要的错因标签。主要错因标签归纳的方式很简单，就对旗下的题目错因进行计数，哪个最多使用哪个，如果相等则会判断优先级。熟练度就有些复杂了，引入了BKT，现在不详细讲，简单说就是它会维护一个数，每当做错题之后，这个数就会变动，最后根据这个数来进行熟练度判断：
```
P(L) < 50%       → weak（薄弱）
50% ～ 70%       → unstable（不稳定）
70% ～ 85%       → familiar（熟悉）
≥ 85%，且至少做过 5 题 → mastered（掌握）
```
当然如果最近连续错了两次也会记录

4
有了这些章节的错因标签和熟练度，那么是怎么把它们变成题目的呢？其实有一张映射表会给LLM,比如概念混淆就会多出选择题，推理错误就会多出简答题。LLM根据这些就会输出练习建议。这些练习建议就会给主编节点，接下来就和正常出题流程一样了

5
那么如果有很多章节都有错误，怎么判断哪道题需要练的多。直接看p(l),哪个大哪个练的多？不是的，最不会不一定现在就要练习，因为如果一个知识点练了很多次都没有改善，那么就不是做题的问题了，而是需要再多看看书了。所以Thompson Sampling 会额外考虑：这个知识点练习后有没有改善潜力

6
那么它具体是怎么排顺序的？其实每个知识点它都有两个数，一个是alpha,一个是beta。alpha代表了值得练的信号，beta代表了不值得练的信号。
```
potential = 1 - P(L)
alpha = 1 + 3 × potential
beta  = 1 + 3 × P(L)
```
上述是p(l)和alpha与beta的关系，当然这只是基础公式。
当p(l)提升的时候，拿到提升幅度reward
```
reward_boost = min(reward, 1) × potential × 2
alpha = alpha+reward_boost
beta  = beta
```
接下来看平均优先级
```
平均优先级 = alpha / (alpha + beta)
```
当然这只是给外面展示用的
真正其实是在alpha和beta里面随机抽样

7
说了那么多，最关键的其实是p(l)是怎么来的
我给好好介绍一下
p(l)的含义是系统觉得学生掌握这道题的概率
这是它的四个参数
```
P(L0) = 0.30  初始掌握概率
P(T)  = 0.15  每做一题后产生学习的概率
P(G)  = 0.20  没掌握但猜对的概率
P(S)  = 0.10  已掌握但失误答错的概率
```
这是我从论文上拿的，但是其实后面根据不同学生的自身情况会修改这个
在做题过程中学生可能学习到一些东西，所以概率得上升
```
P(L) = P(L) + (1 - P(L)) × P(T)
```
如果学生答错的话，有可能是不会，有可能是失误
所以按照贝叶斯公式
```
P(L | 答错)
= P(L) × P(S)
  ─────────────────────────────────────
  P(L) × P(S) + (1 - P(L)) × (1 - P(G))
```
那如果答对也是一样的
```
P(L | 答对)
= P(L) × (1 - P(S))
  ─────────────────────────────────────
  P(L) × (1 - P(S)) + (1 - P(L)) × P(G)
```

系统记录了所有的答题状况，因为答题序列的不同会对概率进行影响，先对后错，先错后对并不一样。

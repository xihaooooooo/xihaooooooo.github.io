BKT算法就是贝叶斯知识追踪，它根据学生每次答题的状况，更新学生对这章节的掌握度。
它的四个参数：
```
p_L0 = 0.30：先验。这个学生第一次接触这个知识点，我先认为他有 30% 的把握。
p_T = 0.15：学习转移。两道题之间，他可能在学——没掌握的部分每次有 15% 的概率补上。
p_G = 0.20：猜测率。没掌握的学生答对一道题的概率。
p_S = 0.10：失误率。掌握了的学生答错一道题的概率。
```
这些默认值都是从论文上面拿下来的，在一开始，可以进行摸底测试，通过摸底测试，可以计算出来p_L0的值是多少。
这个摸底测试是针对于每一大章，并不是一本书或者一个小节。具体算法：
```
30 道题答对 18 道
摸底正确率 r = 18/30 = 60%
猜测率 p_G = 20%
失误率 p_S = 10%
默认 p_L0 = 30%
原始 p_L0
= (正确率 - 猜测率) ÷ (1 - 失误率 - 猜测率)
= (0.60 - 0.20) ÷ (1 - 0.10 - 0.20)
= 0.40 ÷ 0.70
≈ 57.1%
最终 p_L0
= (10 × 30% + 30 × 57.1%) ÷ (10 + 30)
≈ 50.3%
```
具体算法步骤呢：
第一步是进行学习转移：
```
P(L) ← P(L) + (1 - P(L)) × P(T)
```
如果答对的话，做贝叶斯更新：
```
P(答对) = P(L) × (1 - P(S)) + (1 - P(L)) × P(G)
P(L | 答对) = P(L) × (1 - P(S)) / P(答对)
```
答错的话：
```
P(L | 答错) = P(L) × P(S) / [ P(L) × P(S) + (1 - P(L)) × (1 - P(G)) ]
```
不过它很敏感，经常答对三道题掌握率就到90%上去了。不过在后面加了只有连续五道题在80%以上才算熟练，而且对于选择题它的幅度给予下降。


得到每一节的p(l)之后就是根据p(l)来生成练习计划，如果样本较少可以根据1-p(l)来生成练习计划，可后续做题增加之后，这种会有很多弊端。所以我引入了Thompson Sampling
